# .ai/ — このリポジトリのAI向けSSOT

このフォルダは gitignore されている。AI（Claude Code・Codex・Cursor・ChatGPT 等、どれでも）が開発の真実をここに書き、次のセッション・次のAIがここから再開する。チャット履歴は参照しない前提で書く。

## ファイル

- `SPEC.md` … **現在の真実**。目的・スコープ・設計・現状・未決事項・次アクション。状態なので書き換える。追記で伸ばさない
- `DECISIONS.md` … **決定ログ**。いつ・何を・なぜ決め、何を捨てたか。追記のみ。過去の行は直さない
- `notes/` … 任意。調査メモ・議事・下書き。SPEC に昇格したら消してよい

## セッションの約束

1. 開始時に `SPEC.md` を読む。次に `DECISIONS.md` の末尾
2. SPEC の「現状」とコードがズレていたら、先に SPEC を直す
3. 人と合意した決定は、その場で `DECISIONS.md` に追記する（日付・決定・理由・捨てた案）
4. 状態が変わったら `SPEC.md` の該当セクションを現在形に書き換える
5. 未決の論点は「未決事項」に問いの形で残す
6. 終了前に「次アクション」を、次のAIがそのまま着手できる粒度で書く

## 書かないこと

- 憶測。未確認の事実は `未確認` と明記する
- チャットにしか無い決定。書けていない決定は無かったものとして扱う
- 秘密情報（トークン・パスワード・個人情報）。gitignore でも書かない
